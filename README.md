# Kalindi College Voicebox

Anonymous complaint & suggestion box for Kalindi College Students' Union.
Static frontend in `public/`, three serverless API routes in `api/`, shared
auth helper in `lib/`, and data stored in Upstash Redis.

## Deploy in 5 minutes

### 1. Push to GitHub
```bash
git init
git add .
git commit -m "Kalindi Voicebox"
git branch -M main
git remote add origin https://github.com/anubhavbajpaibusiness/kalindi-opress.git
git push -u origin main
